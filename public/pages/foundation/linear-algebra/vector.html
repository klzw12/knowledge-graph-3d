📖 向量的概念

n 维向量：由 $n$ 个实数 $a_1,a_2,\dots,a_n$ 构成的有序数组。

  • 行向量：$\alpha = (a_1, a_2, \dots, a_n)$
  • 列向量：$\alpha = (a_1, a_2, \dots, a_n)^\mathrm{T}$
  • 零向量：所有分量为 0，记作 $\mathbf{0}$

向量的运算

运算定义
加法对应分量相加：$\alpha+\beta = (a_1+b_1,\dots,a_n+b_n)$
数乘每个分量乘以同一数：$k\alpha = (ka_1,\dots,ka_n)$
内积$\alpha^\mathrm{T}\beta = \sum a_i b_i$
模长$\|\alpha\| = \sqrt{a_1^2 + \cdots + a_n^2}$

向量组

  • 定义：同维向量的集合
  • 部分组与整体组：$S_1 \subseteq S$，整体无关$\Rightarrow$部分无关，部分相关$\Rightarrow$整体相关
  • 延伸组 / 缩短组：增/删分量所得。延伸相关$\Rightarrow$缩短相关；缩短无关$\Rightarrow$延伸无关

🔗 线性表示与线性相关

基本定义

$$\text{线性组合:}\quad k_1\alpha_1 + \cdots + k_m\alpha_m$$
  • 线性表示：$\beta$ 可写为 $\alpha_1,\dots,\alpha_m$ 的线性组合
  • 线性相关：存在不全为 0 的 $k_i$ 使 $\sum k_i\alpha_i = \mathbf{0}$
  • 线性无关：仅当所有 $k_i=0$ 时 $\sum k_i\alpha_i = \mathbf{0}$
⚠️ 注意

含零向量的向量组必线性相关。单个零向量相关，单个非零向量无关。

考研核心：线性表示 ⇄ 方程组秩

$$\beta \text{ 可由 } \alpha_1,\dots,\alpha_n \text{ 线性表示} \iff r(\alpha_1,\dots,\alpha_n) = r(\alpha_1,\dots,\alpha_n,\beta)$$

即：把 $\beta$ 拼到向量组末尾，秩不变 $\iff$ $\beta$ 可被表示。

推论 2 的桥梁作用：当向量个数等于维数时，线性相关性问题直接转化为行列式计算——这是连接第三章和第一章的关键。

📏 极大线性无关组与秩

极大线性无关组：向量组中线性无关且无法再添加向量的子组。其向量个数即为秩，记 $r(\alpha_1,\dots,\alpha_m)$。

$$r(\alpha_1,\dots,\alpha_m) = \text{极大无关组中向量的个数}$$

等价向量组

两个向量组可互相线性表示 $\iff$ 等价，此时秩相等。

$$\text{(I) 等价于 (II)} \iff r(\text{I}) = r(\text{II})$$

三秩相等（与矩阵的桥梁）

$$r(A) = \text{行秩} = \text{列秩}$$

矩阵的秩 = 行向量组的秩 = 列向量组的秩。这意味着：向量组的秩可以用矩阵的初等变换来求——把向量排成矩阵，行阶梯形数非零行即可。

📐 施密特正交化 (Gram-Schmidt)

给定线性无关组 $\alpha_1,\dots,\alpha_m$，构造正交组 $\beta_1,\dots,\beta_m$：

$$\begin{aligned} \beta_1 &= \alpha_1, \\ \beta_k &= \alpha_k - \sum_{i=1}^{k-1} \frac{(\alpha_k,\beta_i)}{(\beta_i,\beta_i)} \beta_i \quad (k=2,\dots,m) \end{aligned}$$

核心思想：每步减去新向量在已有正交基上的投影，剩余分量即为正交部分。之后再单位化（除以模长）得标准正交组。

用途：将任意基转化为标准正交基，是 QR 分解、最小二乘法等算法的基础。

🔄 正交矩阵

$$A^\mathrm{T}A = AA^\mathrm{T} = I$$
条件等价性质
定义$A^\mathrm{T}A = I$
逆$A^{-1} = A^\mathrm{T}$
行列式$|A| = \pm 1$
列向量单位向量且两两正交
行向量单位向量且两两正交
保范性$\|Ax\| = \|x\|$（正交变换不改变向量长度）
💡 直觉

正交矩阵对应的是旋转或反射——不伸缩、不变形，只改变方向。所以 $|A| = \pm 1$：$+1$ 是旋转，$-1$ 是反射。

解空间的判定流程

拿到一个线性方程组问题，按以下顺序判定：

  1. $A$ 是方阵？→ 先算 $|A|$（快筛）
  2. $|A| \neq 0$ → 唯一解（有解时）/ 只有零解（齐次时）
  3. $|A| = 0$ 或 $A$ 不是方阵 → 用秩：$r(A)$ vs $r(A|b)$
  4. $r(A) = r(A|b) = n$ → 唯一解；$r(A)=r(A|b) < n$ → 无穷多解；$r(A) < r(A|b)$ → 无解

🔑 关键概念

  • 线性相关 / 无关 — 向量组"有无冗余"的判断，相关 ⇔ 至少一个可被其余表示
  • 线性表示 ⇄ 秩相等 — 考研最核心等价：$\beta$ 可被表示 $\iff$ 添加后秩不变
  • 极大无关组 — 向量组的"骨架"，去掉冗余向量后剩下的最小生成集
  • 三秩相等 — 行秩 = 列秩 = 矩阵秩，打通了行/列/向量三个视角
  • 施密特正交化 — 逐次减去投影，把任意基化为正交基
  • 正交矩阵 — $A^{-1}=A^\mathrm{T}$，对应旋转/反射变换，不改变向量长度
  • 解空间判定 — 方阵先试行列式，非方阵用秩，这是最系统的思路

🔗 关联

  • 行列式 — 推论 2 将相关性判断转化为 $|A|$ 计算（仅有向量个数=维数时）
  • 矩阵运算 — 三秩相等打通向量组秩与矩阵秩，向量排成矩阵即可求秩
  • PCA 主成分分析 — 本质是在高维向量空间中找一组标准正交基（特征向量）
  • 最小二乘法 — 基于正交投影，施密特正交化是其核心计算步骤
