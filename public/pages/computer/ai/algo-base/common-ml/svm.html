SVM Support Vector Machine

通过寻找最大间隔超平面来进行分类或回归，擅长高维小样本数据

📄 Support-Vector Networks, Vapnik 1995
目录
📖 定义 📐 数学原理 🔑 关键概念 🔗 关联

📖 定义

Support Vector Machine — 在特征空间中寻找一个能将不同类别样本分开且间隔最大的超平面。只依赖少数关键样本（支持向量）决定分类边界，泛化能力强。

📐 数学原理

硬间隔 SVM

最大化间隔等价于最小化 \$\\|\\mathbf{w}\\|\$：

$$\min_{\mathbf{w},b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^\mathsf{T}\mathbf{x}_i + b) \geq 1, \forall i$$

软间隔（允许误分类）

引入松弛变量 \$\\xi_i\$，由参数 C 控制惩罚力度：

$$\min_{\mathbf{w},b,\boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^n \xi_i$$

核技巧

通过核函数 \$K(\\mathbf{x}_i,\\mathbf{x}_j)\$ 隐式映射到高维空间。常用核：线性核、多项式核、RBF 高斯核

$$K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma\|\mathbf{x}_i - \mathbf{x}_j\|^2)$$

🔑 关键概念

  • 支持向量 — 决定边界的少数样本
  • 核技巧 — 处理非线性问题
  • 对偶问题 — 用拉格朗日乘子法求解
  • C 参数 — 控制间隔惩罚力度
  • γ 参数 — RBF 核的影响半径

🔗 关联

  • 逻辑回归（线性分类器对比）
  • Kernel PCA（核方法）
  • 神经网络（深层分类器）
着重注意
💡 要点 SVM 在小样本高维场景下表现优异，核函数的选择是关键
⚠️ 局限 大数据集训练慢(O(n²~n³))，多分类需一对一/一对多策略
🔧 实践 使用前必须做特征标准化，RBF核通常优于线性核，用交叉验证选C和γ
