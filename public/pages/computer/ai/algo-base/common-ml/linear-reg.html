📖 定义

Linear Regression — 假设目标变量 y 与特征 x 之间存在线性关系，通过学习权重 w 和偏置 b 来最小化预测值与真实值之间的误差。是统计学和机器学习的基石模型。

📐 数学原理

模型形式

简单线性回归（单变量）：

$$y = wx + b$$

多元线性回归：

$$\hat{y} = \mathbf{w}^\mathsf{T}\mathbf{x} + b$$

矩阵形式：

$$\mathbf{y} = \mathbf{X}\mathbf{w}$$

损失函数

均方误差 (MSE)：

$$\mathcal{L}(\mathbf{w}) = \frac{1}{n}\|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2$$

解析解

正规方程 (Normal Equation)：

$$\mathbf{w} = (\mathbf{X}^\mathsf{T}\mathbf{X})^{-1}\mathbf{X}^\mathsf{T}\mathbf{y}$$

🔑 关键概念

  • 最小二乘法 — 使残差平方和最小
  • 梯度下降 — 在大规模数据上的数值优化方法
  • 决定系数 R² — 模型拟合优度的度量
  • 过拟合与正则化 — Ridge(L2)、Lasso(L1) 回归

🔗 关联

  • 逻辑回归（分类任务）
  • Ridge / Lasso 回归（正则化变体）
  • SVM 回归 (SVR)（间隔最大化回归）
着重注意
💡 要点 线性回归的解析解(O(n³))在大数据上不可行，此时用梯度下降
⚠️ 局限 只能捕捉线性关系，对异常值敏感
🔧 实践 用之前先做特征标准化，检查残差是否满足正态性和同方差性
🌳 演进 线性回归衍生出 Ridge、Lasso、弹性网络等正则化变体，并通过 Sigmoid 函数催生了逻辑回归（回归→分类的范式跃迁）
