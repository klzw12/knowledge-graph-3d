📖 定义

334|

Linear Regression 是一种统计技术，用于寻找变量之间的关系。在机器学习语境中，线性回归寻找特征 (feature) 与标签 (label) 之间的线性关系。

335|

例如：预测汽车的燃油效率（英里/加仑）与车重（千磅）之间的关系：

📐 数学原理

354| 355|

模型形式

356|

简单线性回归（单变量，一个特征）：

357|
$$y' = b + w_1 x_1$$
358|

其中：y' 是预测标签，b 是偏置（bias/y-截距），w₁ 是权重（weight/斜率），x₁ 是特征值。

359| 360|

多元线性回归（多特征）：

361|
$$y' = b + w_1 x_1 + w_2 x_2 + \cdots + w_n x_n$$
362|
$$\hat{y} = \mathbf{w}^\mathsf{T}\mathbf{x} + b$$
363| 364|
365|
💡 示例
366|

在车重预测燃油效率的例子中：偏置 b = 34（y 轴截距），权重 w₁ = −4.6（斜率）。

367|

模型：y' = 34 + (−4.6)(x₁)

368|

一辆 4000 磅的车（x₁ = 4.0），预测燃油效率为 34 + (−4.6)(4.0) = 15.6 mpg。

📉 损失函数 (Loss)

375|

损失 是一个数值度量，描述模型的预测有多"错误"。损失衡量模型预测与真实标签之间的距离。 376| 训练模型的目标就是将损失降到最低。

377|

损失只关心距离，不关心方向（正负号），所以需要消去符号。两种常用方法：取绝对值、或取平方。

378| 379|

损失类型一览

380|
381| 382| 383| 384| 385| 386| 387| 388| 389| 390| 391| 392| 393| 394| 395| 396| 397| 398| 399| 400| 401| 402| 403| 404| 405| 406| 407| 408|
损失类型定义公式
L₁ Loss预测与真实值之差的绝对值之和Σ|actual − predicted|
MAE
Mean Absolute Error		L₁ Loss 的均值(1/N) Σ|actual − predicted|
L₂ Loss预测与真实值之差的平方和Σ(actual − predicted)²
MSE
Mean Squared Error		L₂ Loss 的均值(1/N) Σ(actual − predicted)²
RMSE
Root MSE		MSE 的平方根（与预测值同量纲）√MSE
409|
410| 411|

MSE 公式（常用）

412|
$$\mathcal{L}(\mathbf{w}) = \frac{1}{n}\sum_{i=1}^{n}\bigl(y_i - \hat{y}_i\bigr)^2$$
413| 414|

L₁ vs L₂ 的选择

415|

平方的作用：当预测偏差很大时，平方会使损失更大；当偏差很小（<1）时，平方使损失更小。L₂ Loss 对异常值 (outliers) 的惩罚远大于 L₁ Loss。

416|

MAE vs RMSE：MAE 代表平均预测误差，RMSE 代表误差的"弥散程度"，对大误差更敏感。MSE 使模型向异常值靠近，MAE 则不受异常值过度影响。

417|

推荐：处理多个样本时，建议对所有样本的损失取平均（无论使用 MAE、MSE 还是 RMSE）。

418| 419|
420|
🧮 计算示例
421|

模型：y' = 34 + (−4.6)(x₁)。实际：一辆 2370 磅的车（x₁=2.37）燃油效率为 24 mpg。

422|

预测值 = 34 + (−4.6)(2.37) = 23.1 mpg

423|

L₂ Loss = (24 − 23.1)² = 0.81

⬇️ 梯度下降 (Gradient Descent)

430|

梯度下降 是一种迭代式数学优化技术，通过反复更新权重和偏置来找到损失最低的模型参数。

431| 432|

迭代过程

433|

模型从随机初始化的权重和偏置（接近 0）开始，重复以下步骤：

434|
    435|
  1. 用当前权重和偏置计算损失
    2. 436|
  2. 确定方向（梯度方向）——朝哪个方向调整参数可以减少损失
    3. 437|
  3. 将权重和偏置向降低损失的方向移动一小步
    4. 438|
  4. 返回步骤 1，反复迭代直至模型收敛
    5. 439|
440| 441|

损失曲线 (Loss Curve)

442|

训练过程中的损失曲线展示损失随迭代次数的变化。典型的损失曲线呈先陡降 → 逐渐趋缓 → 最终平缓的模式：

443|
    444|
  • 早期迭代：损失急剧下降，模型快速改善
    • 445|
  • 中期迭代：损失逐渐下降，改进幅度变小
    • 446|
  • 收敛：损失线变平，模型达到最低损失点
    • 447|
448| 449|

凸函数与收敛

450|

线性回归的损失函数总是凸的 (convex)，这意味着它只有一个全局最小值。当梯度下降收敛时，可以确信找到了使损失最小的权重和偏置。

451|

可以把梯度下降想象成一个球滚下坡：每次迭代就是在坡上迈出一步，最终停在谷底（全局最低点）。

452|

⚠️ 注意：模型几乎从不会找到恰好让损失归零的精确值，而是找到非常接近的值。损失恰好为 0 通常意味着过拟合。

453|

⚙️ 超参数 (Hyperparameters)

458|

超参数 是你在训练前设定的变量，控制训练过程的各个方面。与参数（权重和偏置，由模型自动计算）不同，超参数需要你手动调节。

459| 460|

学习率 (Learning Rate)

461|

学习率是一个浮点数，控制模型收敛的速度。模型将梯度乘以学习率来确定下一步的步长。

462|
    463|
  • 太小的学习率：每一步修改极小，需要极多迭代才能收敛
    • 464|
  • 适中的学习率：快速稳定收敛
    • 465|
  • 太大的学习率：模型无法收敛，损失曲线上下震荡甚至发散
    • 466|
467|

理想的学习率是"问题相关"的（problem-dependent），通常需要试错调整。

468| 469|

批次大小 (Batch Size)

470|

批次大小是指模型在每次更新权重和偏置前处理的样本数量。三种常见模式：

471| 472|
473| 474| 475| 476| 477| 478| 479| 480| 481| 482| 483| 484| 485| 486| 487| 488| 489| 490|
批次策略每轮处理样本数特点
Full-Batch全部样本计算精确，但大数据集上不实用
SGD
Stochastic GD		1 个样本（随机选取）收敛可行但非常"嘈杂"，损失曲线抖动明显
Mini-Batch SGD1 ~ N 之间的任意数字折中方案，实际中最常用。例如 batch_size=32
491|
492| 493|

小批次行为类似 SGD，大批次行为类似 Full-Batch。批次大小还受可用计算资源限制。

494|

💡 一定程度的"噪声"其实是有益的——它能帮助模型更好地泛化。

495| 496|

Epoch（轮次）

497|

1 个 epoch 意味着模型已经处理完训练集中每个样本一次。例如：1000 个样本、batch_size=100 的情况下，需要 10 次迭代完成 1 个 epoch。

498|

训练通常需要多个 epochs。一般来说，更多 epochs 产生更好的模型，但训练时间也更长。
