📖 定义

333|

弹性网络 (Elastic Net) 是一种线性回归的正则化变体，由 Hui Zou 和 Trevor Hastie 于 2005 年提出。它将 L1 正则化（Lasso）和 L2 正则化（Ridge）的惩罚项以加权和的形式合并到损失函数中，兼收两者之长。

334|

从数学上说，弹性网络在最小化均方误差 (MSE) 的同时，对模型权重施加 L1 + L2 混合约束。这种双重正则化带来的两个核心特性是：

335|
    336|
  • 稀疏性 (Sparsity) — 来自 L1 项，可以将不重要特征的权重强制归零，实现自动特征选择
    • 337|
  • 组效应 (Grouping Effect) — 来自 L2 项，使强相关特征的权重要么同时保留、要么同时移除，而不是像 Lasso 那样随机选择其中一个
    • 338|
339|

弹性网络的创新之处在于：它不是简单地在回归损失后加上一个惩罚项，而是设计了同时包含 L1 范数和 L2 范数平方的"弹性"惩罚，通过两个参数调节各自的强度。这种设计使得它在处理高维数据（特征数 > 样本数）和强相关特征群组时，表现优于单纯的 Lasso 或 Ridge。

340|

直观理解：L1 正则化像是一把"高效的手术刀"——精准但可能过于激进；L2 正则化像是一副"均匀的紧箍咒"——稳定但缺乏取舍能力。弹性网络将二者结合，得到了既能剔除非必要特征又能稳定处理相关特征群的模型。

📐 数学原理

346| 347|

损失函数定义

348|

弹性网络的损失函数由三部分组成：数据拟合项（MSE）、L1 惩罚项和 L2 惩罚项。最直接的表达形式为：

349|
$$\mathcal{L}(\mathbf{w}) = \frac{1}{2n}\sum_{i=1}^{n}\bigl(y_i - \hat{y}_i\bigr)^2 + \lambda_1\sum_{j=1}^{p}|w_j| + \lambda_2\sum_{j=1}^{p}w_j^2$$
350|

其中：

351|
    352|
  • $\frac{1}{2n}\sum(y_i - \hat{y}_i)^2$ — 均方误差（除以 2 是为了求导方便）
    • 353|
  • $\lambda_1\sum|w_j|$ — L1 惩罚项（系数 $\lambda_1 \ge 0$ 控制 L1 强度）
    • 354|
  • $\lambda_2\sum w_j^2$ — L2 惩罚项（系数 $\lambda_2 \ge 0$ 控制 L2 强度）
    • 355|
  • $n$ 为样本数，$p$ 为特征数
    • 356|
357| 358|

等价参数化形式

359|

为了方便调参，弹性网络通常使用另一种等价的参数化形式，引入一个混合参数 $\alpha$ 和总正则化强度 $\lambda$：

360|
$$\mathcal{L}(\mathbf{w}) = \frac{1}{2n}\sum_{i=1}^{n}\bigl(y_i - \hat{y}_i\bigr)^2 + \lambda\Bigl[(1-\alpha)\sum_{j=1}^{p}|w_j| + \alpha\sum_{j=1}^{p}w_j^2\Bigr]$$
361|

在这种形式中：

362|
    363|
  • $\lambda \ge 0$ — 总体正则化强度，越大则权重越趋向于 0
    • 364|
  • $\alpha \in [0, 1]$ — L1 和 L2 的混合比例
    • 365|
  • $\alpha = 0$ 时退化为纯 Lasso
    • 366|
  • $\alpha = 1$ 时退化为纯 Ridge
    • 367|
368| 369|

与朴素 Elastic Net 的缩放差异

370|

许多实现（包括 Scikit-learn）使用的形式略微不同，加入了缩放因子 $1 - \alpha$ 使得 $\lambda$ 在各 $\alpha$ 取值下可比：

371|
$$\mathcal{L}(\mathbf{w}) = \frac{1}{2n}\text{MSE} + \lambda\Bigl(\frac{1-\alpha}{2}\sum_{j=1}^{p}|w_j| + \frac{\alpha}{2}\sum_{j=1}^{p}w_j^2\Bigr)$$
372|

这种约定下，$\alpha = 0.5$ 表示 L1 和 L2 的贡献大致相等。不同库的实现细节略有不同，使用前应查阅文档确认具体公式。

373| 374|
375|
🧮 可视化理解
376|

Ridge 的约束区域是一个圆形（L2 球），Lasso 的约束区域是一个菱形（L1 球）。弹性网络的约束形状介于两者之间——当 L1 占主导时趋近菱形，L2 占主导时趋近圆形。这就像在一个"四角被磨圆了的菱形"内部寻找最优解。

377|

最优解出现在 MSE 的等高线与约束区域的首次接触点。菱形尖角接触坐标轴更容易产生稀疏解（某些权重为零），圆形曲面则使相关特征的系数趋向均衡。

378|
379| 380|

求解方法

381|

弹性网络的目标函数是凸函数——L1 项为凸，L2 项为严格凸，MSE 为凸，所以整体严格凸。这意味着有唯一的全局最优解。常用的求解算法包括：

382|
    383|
  • 坐标下降 (Coordinate Descent) — 逐维迭代优化，每次固定其他维度优化一个 $w_j$，是 Lasso 和 Elastic Net 最主流的求解方法
    • 384|
  • 最小角回归 (LARS) — 基于角度的逐步选择算法，效率高且可同时输出全路径解
    • 385|
  • 随机梯度下降 (SGD) — 适合大规模数据，通过在线方式逐样本更新
    • 386|
387|

坐标下降法在弹性网络中尤其高效，因为 Elastic Net 的逐维子问题有闭式解（软阈值算子 + L2 收缩的组合）。

🎯 为什么需要 ElasticNet

393| 394|

Lasso 的两个关键局限

395|

Lasso（L1 正则化）虽然在特征选择上表现出色，但在某些场景下存在结构性缺陷：

396| 397|

1. 特征数量限制

398|

当数据维度极高时（$p \gg n$，即特征数远大于样本数），Lasso 最多只能选择 $n$ 个非零特征。这是一个硬性上限——无论数据中实际上有多少个重要特征，Lasso 都无法选出超过样本数的非零系数。例如，100 个样本、10000 个特征的数据集中，Lasso 最多只能选 100 个特征，即使真实模型需要 200 个特征。

399| 400|

2. 相关特征组的随机选择

401|

当多个特征彼此高度相关时（如基因表达数据中处于同一通路的一群基因），Lasso 倾向于随机选择其中一个，而将其他相关特征的系数压为 0。这意味着：

402|
    403|
  • 最终选出的特征可能并非真正"最重要"的那个，只是随机结果
    • 404|
  • 模型的可解释性和稳定性下降（换一份数据可能选出完全不同的特征子集）
    • 405|
  • 丢失了相关特征组中包含的群体信息
    • 406|
407| 408|

ElasticNet 的解决之道

409|

弹性网络从两个角度克服了上述局限：

410| 411|

应对特征数量限制 — 加入 L2 项后，整体损失函数的严格凸性（Ridge 提供）使得优化问题的解不再受"最多选 n 个非零系数"的限制。L2 项的正则化效应使得特征选择不再受样本数的硬性约束。

412| 413|

实现组效应 (Grouping Effect) — L2 正则化鼓励相关特征的系数彼此靠近：如果两个特征高度相关且都包含有用信息，L1 只会倾向保留一个而舍弃另一个，但 L2 会"拉着"它们的系数一起变大或一起缩小。结果是高度相关的特征群要么一起被选入模型，要么一起被排除，而非随机挑选。

414| 415|
416|
💡 典型案例
417|

在基因表达数据分析中，同一生物通路中的多个基因表达水平往往高度相关。如果使用 Lasso，它会随机选择一个基因而排除其他，丢失了该通路的生物信息。ElasticNet 能够同时保留整个通路的相关基因，使得模型在生物学意义上更合理、预测更稳定。

📊 参数 α 的意义

424|

$\alpha$ 是弹性网络的核心超参数，控制 L1 与 L2 正则化的混合比例。其取值范围为 $[0, 1]$，两端对应着两种经典算法：

425| 426|
427| 428| 429| 430| 431| 432| 433| 434| 435| 436| 437| 438| 439| 440| 441| 442| 443| 444|
$\alpha$ 取值等价模型行为特征
$\alpha = 0$Lasso纯 L1 正则化，强特征选择能力，可能随机剔除相关特征
$\alpha = 1$Ridge纯 L2 正则化，稳定处理相关特征但不产生稀疏解
$0 < \alpha < 1$Elastic Net混合行为，兼具特征选择与组效应
445|
446| 447|

α 取值的影响

448|

$\alpha$ 接近 0（接近 Lasso）：模型偏向产生稀疏解，大量特征的权重被归零。适合你确信绝大多数特征是噪声、只有少数特征真正有意义的场景。但代价是强相关特征间的"随机选择"问题仍然存在。

449|

$\alpha$ 接近 1（接近 Ridge）：所有特征权重都被"均匀收缩"但不会归零，组效应显著。适合特征间存在复杂相关性、需要保持所有特征贡献的场景。缺点是模型变得不够简洁，所有特征都被保留。

450|

$\alpha$ 在中间值（如 0.5）：这是弹性网络最"独特"的区域——既施加足够的 L1 压力来剔除无关特征，又利用 L2 的均匀收缩力来实现组效应。实际应用中，$\alpha = 0.5$ 常被用作默认起点，然后通过交叉验证搜索最优点。

451| 452|

通常如何选择 α

453|

实际调参策略推荐：

454|
    455|
  • 先用 $\alpha = 0.5$ 作为基线，配合交叉验证优化 $\lambda$
    • 456|
  • 如果希望更稀疏的模型（更多权重归零），降低 $\alpha$（朝 Lasso 方向）
    • 457|
  • 如果希望更强的组效应（相关特征群共同保留），提高 $\alpha$（朝 Ridge 方向）
    • 458|
  • 在最终模型中，可以使用网格搜索（Grid Search）在 $\alpha$ 和 $\lambda$ 的二维网格上联合调参
    • 459|
460| 461|
$$\text{调参网格：}\quad \alpha \in \{0.1, 0.3, 0.5, 0.7, 0.9\},\quad \lambda \in [10^{-4}, 10^{2}]$$
462| 463|

二次超参数 λ 的含义

464|

$\lambda$ 控制整体的正则化惩罚强度：

465|
    466|
  • $\lambda$ 很大 — 惩罚项占主导，所有权重都被强力推向 0（过高的正则化，模型欠拟合）
    • 467|
  • $\lambda$ 很小 — 几乎不计入惩罚，模型趋向普通线性回归（可能过拟合）
    • 468|
  • $\lambda$ 适中 — 在偏差和方差之间取得最佳平衡
    • 469|
470|

通常通过交叉验证（如 5 折 CV）在 $\lambda$ 的取值路径上搜索最小验证误差对应的 $\lambda$。许多实现（如 Scikit-learn 的 ElasticNetCV）内置了沿 $\lambda$ 路径的搜索。

🌳 演进关系 (Evolution)

476|

弹性网络是正则化回归演进的集大成者，站在 Ridge 和 Lasso 的肩膀上实现了关键创新：

477| 478|
479|
线性回归
480|
481|
⭐ 岭回归 (Ridge) L2 正则化 · 1970
482|
⭐ Lasso L1 正则化 · 1996
483|
🌈 ElasticNet L1+L2 融合 · 2005

486| 487|

从 Ridge 到 Lasso

488|

1970 年提出的 Ridge 回归（Hoerl & Kennard）首次将 L2 惩罚引入线性回归，解决了特征间多重共线性问题，使得病态矩阵仍可求逆。然而 Ridge 不能将系数精确归为零，所以不产生稀疏解。

489|

1996 年 Lasso（Tibshirani）用 L1 惩罚替代 L2，通过绝对值的几何特性（菱形尖角触及坐标轴）实现了系数精确归零，开创了嵌入式特征选择的方法论。但如前述，Lasso 在高维和组相关特征场景下有局限。

490| 491|

ElasticNet 的融合创新

492|

2005 年 Zou 和 Hastie 在论文 "Regularization and Variable Selection via the Elastic Net" 中证明：

493|
    494|
  • 形式上的融合 — 将 L1 和 L2 惩罚以加权和的形式组合在一个损失函数中
    • 495|
  • 理论上的必然性 — 证明在任何固定 $\lambda > 0$ 的条件下，当 $\alpha \to 0$ 时弹性网络的解趋于 Lasso；当 $\alpha \to 1$ 时趋于 Ridge
    • 496|
  • 组效应的理论保证 — 论文给出了弹性网络解中组效应的理论边界：两个相关特征的系数差被 $\alpha$ 和 $\lambda$ 控制在一个范围之内
    • 497|
  • 特征选择上限的突破 — 由于 L2 项的存在，弹性网络可以选出超过 $n$ 个非零特征
    • 498|
