Lasso 回归 LASSO Regression — Least Absolute Shrinkage and Selection Operator

在最小二乘法基础上加入 L1 正则化惩罚项，以权重绝对值之和约束模型复杂度。 不仅能够防止过拟合，更能自动将不重要的特征权重压缩至零，实现特征选择。

📖 定义

Lasso 回归（Least Absolute Shrinkage and Selection Operator，最小绝对收缩与选择算子）由 Robert Tibshirani 于 1996 年提出，是一种在普通最小二乘（OLS）损失函数中加入 L1 正则化惩罚项 的线性回归方法。

与 Ridge 回归（L2 正则化）不同，Lasso 的 L1 惩罚项会将某些特征的权重精确压缩为 零，从而实现自动特征选择——这是 Lasso 最核心也最独特的性质。

换句话说：Lasso 同时做了两件事——拟合模型（最小化预测误差）和筛选特征（将不重要的系数置零），特别适合处理高维稀疏数据和特征数量远多于样本数量的场景。

💡 直觉理解

想象你要在 100 个可能的因素中预测房价，但真正有用的只有 5 个。普通线性回归会保留所有 100 个系数（即使它们很小且充满噪声），而 Lasso 会自动将 95 个无关特征的系数精确设为 0——只保留那 5 个关键特征。

由来与命名

"Lasso" 的全称揭示了它的三个核心动作：Least Absolute（最小绝对值 — 使用 L1 范数）、Shrinkage（收缩 — 将系数向零压缩）、Selection Operator（选择算子 — 将无关系数设为 0）。这个名称精准概括了 Lasso 的全部工作原理。

📐 数学原理

损失函数

Lasso 回归的目标函数由两部分组成：MSE 损失 + L1 正则化惩罚项：

$$L(\mathbf{w}) = \text{MSE}(\mathbf{w}) + \lambda \sum_{j=1}^{p} |w_j|$$

其中 MSE 是均方误差项，衡量模型对训练数据的拟合程度；λ·Σ|wⱼ| 是 L1 正则化项，对所有权重的绝对值之和进行惩罚；λ ≥ 0 是正则化强度超参数，控制惩罚力度。展开形式为：

$$L(\mathbf{w}) = \frac{1}{2n}\sum_{i=1}^{n}\bigl(y_i - \hat{y}_i\bigr)^2 + \lambda\sum_{j=1}^{p}|w_j|$$

注意：惯例上偏置项 w₀（截距）不参与正则化惩罚，因为只对特征权重进行收缩。

为什么 L1 能产生稀疏解？

关键在于 L1 范数的几何形状。约束优化视角下，Lasso 等价于在满足 Σ|wⱼ| ≤ t 的条件下最小化 MSE。L1 正则化的约束区域是一个菱形（二维）或八面体（高维），其顶点和棱边落在坐标轴上。

当 MSE 的等高线（椭圆）与菱形约束区域相切时，切点很容易落在坐标轴上，导致某些维度的权重恰好为 0。相比之下，L2 正则化的约束区域是圆形（平滑无尖角），切点极少落在坐标轴上，因此不会产生精确的零权重。

🧮 简单例子（二维）

假设只有两个特征 w₁ 和 w₂。Lasso 的约束是 |w₁| + |w₂| ≤ t（菱形）。MSE 的最低点若在菱形外部，则最优解会"贴"在菱形的角上——即 w₁ = 0 或 w₂ = 0 的位置。Ridge 的约束是 w₁² + w₂² ≤ t（圆），最优解几乎不可能落在坐标轴上，因此 Ridge 不会产生精确的零系数。

优化求解

由于 L1 范数在原点处不可导（|w| 在 w=0 处导数不存在），无法直接用标准的梯度下降法求解。Lasso 的优化主要有两种方法：

  • 坐标下降法 (Coordinate Descent) — 最常用的方法。每次只优化一个特征 wⱼ，固定其他所有特征。对每个系数，利用软阈值公式（subgradient 条件）直接更新，单变量更新为闭式解，计算快速。sklearn 的 Lasso 实现即基于此。
  • LARS (Least Angle Regression) — 由 Efron 等人提出。将 λ 从大到小逐步放松，沿着解路径前进，每次加入一个特征。计算效率极高，甚至可以输出完整解路径。
  • 子梯度下降 (Subgradient Descent) — 理论上可行，但收敛较慢，实践中较少使用。

软阈值公式（坐标下降核心）

对 Lasso 目标函数关于 wⱼ 求子梯度并令其为零，得到坐标下降法的更新公式：

$$\hat{w}_j = S_{\lambda}\!\left(\frac{1}{n}\sum_{i=1}^{n} x_{ij}\,r_i^{(j)}\right)$$

其中 $r_i^{(j)} = y_i - \sum_{k \neq j} w_k x_{ik}$ 是去掉第 j 个特征后的残差，$S_{\lambda}(\cdot)$ 是软阈值算子：

$$S_{\lambda}(z) = \operatorname{sign}(z) \cdot \max\!\bigl(|z| - \lambda,\;0\bigr)$$

软阈值算子的含义很直观：当 |z| ≤ λ 时输出 0（特征被淘汰）；当 |z| > λ 时向原点收缩 λ 个单位。这一简单公式保证了 Lasso 解的稀疏性和收缩性。

🔍 稀疏性与特征选择

几何直觉

理解 Lasso 特征选择能力的关键是观察 L1 约束区域的几何形状。在二维参数空间中，L1 约束 |w₁| + |w₂| ≤ t 是一个旋转 45° 的菱形。该菱形的四个"尖角"分别位于坐标轴上：(t,0)、(0,t)、(-t,0)、(0,-t)。

对于普通最小二乘解的等高线（椭圆）与这个菱形约束求交点时：

  • 由于椭圆的延伸方向通常不与坐标轴对齐，切点更可能落在尖角（坐标轴）上，而非边或内部
  • 在尖角处，其中一个坐标分量恰好为零——这就是稀疏性的几何来源
  • 在高维空间中，L1 约束区域是交叉多面体 (cross-polytope)，其顶点均在坐标轴上。切点落在这些顶点上的概率随维度增加而增大，因此高维稀疏性更为显著

Ridge 为什么做不到？

对照来看，Ridge 的 L2 约束 w₁² + w₂² ≤ t 是一个圆盘。圆盘的边界是光滑的，没有任何尖角或棱边。当 MSE 的椭圆等高线与该圆盘相切时，切点几乎不可能精确落在坐标轴上——因为需要椭圆的主轴恰好与坐标轴完美对齐，这在实践中几乎不会发生。

因此 Ridge 虽然能收缩系数（使其变小），但不能将任何系数精确置零。

特征选择的实际影响

Lasso 的自动特征选择能力在以下场景中尤为重要：

  • 高维数据（特征数 p 远大于样本数 n）：在 p > n 的情况下，OLS 无唯一解，但 Lasso 依然能选出最多 n 个非零特征（λ 足够大时）
  • 噪声特征过滤：当数据中含有大量无关或冗余特征时，Lasso 自动忽略它们
  • 模型可解释性：只保留少数特征的模型更容易理解和解释
  • 降低过拟合：减少特征数量即降低模型复杂度，提升泛化能力
⚠️ 特征组问题

Lasso 的一个重要局限：当一组高度相关的特征同时存在时，Lasso 倾向于只从该组中随机选择一个，而将组内其他特征的系数置零。这会导致模型在相关特征子集上不稳定。ElasticNet（L1+L2 混合）通过加入 L2 惩罚部分解决了这个问题，使相关特征被同时保留（或同时剔除）。

📊 L1 vs L2 对比

何时用 Lasso

  • 特征数量远多于样本（p ≫ n）：Lasso 能有效降维，选出最有用的特征子集
  • 你怀疑大多数特征都是无关的：Lasso 的稀疏解自动剔除无用特征，保留关键信号
  • 需要高可解释性：模型只依赖少数特征，容易向业务方解释
  • 做特征选择的预处理：先用 Lasso 选出候选特征，再用其他模型做精确拟合

何时用 Ridge

  • 所有特征都可能有用：Ridge 保留所有特征，只是对系数均匀收缩，不丢弃任何特征
  • 特征间存在多重共线性：Ridge 能有效稳定共线性下的系数估计
  • 预测精度优先，可解释性次要：Ridge 通常比 Lasso 有略低的预测方差
  • 特征数量中等（n ≫ p 且特征数量不大）：Ridge 的均匀收缩不会浪费太多

何时用 ElasticNet

  • Lasso 在相关特征组中"随机挑选单特征"的行为不可接受时
  • 二者兼顾：既要稀疏性（L1），又要稳定处理特征分组（L2）
  • 数据集特征之间分组相关结构明显时

λ 的调参策略

正则化强度 λ 是 Lasso 最重要的超参数，需要仔细调节：

  • λ = 0：退化为普通最小二乘（OLS），无正则化
  • λ 趋近 ∞：所有权重被压缩到 0，模型退化为常数预测
  • 交叉验证选择 λ：最常用的是 k 折交叉验证，选择 CV 误差最小的 λ（或 1 个标准误内的最大 λ，即 lambda_1se，更稀疏的模型）
  • λ 路径（Regularization Path）：从大到小生成一系列 λ 值，观察每个 λ 下系数的变化轨迹。这是诊断特征重要性的有力工具
💡 实用建议

实践中最常用的方法是 sklearn 的 LassoCV，它会自动在 λ 路径上做交叉验证选择最优 λ。用 warm start 技术（以上次 λ 的解初始化本次优化）可以极大加速 λ 路径的搜索过程。

衍生变体

  • ElasticNet (弹性网络) — ZOU & HASTIE (2005)：结合 L1 + L2 惩罚，既实现稀疏性（L1 长处）又稳定处理相关特征组（L2 长处）。损失函数为 MSE + λ₁Σ|wⱼ| + λ₂Σwⱼ²。
  • Adaptive Lasso — ZOU (2006)：不同特征施加不同的惩罚权重，重要特征惩罚小、不重要特征惩罚大，提高变量选择的偏差一致性和 Oracle 性质。
  • Group Lasso — YUAN & LIN (2006)：特征以组为单位进行选择，要么整组保留、要么整组丢弃。适用于分类变量（one-hot 编码的虚拟变量组）。
  • LARS (Least Angle Regression) — EFRON et al. (2004)：一种高效求解 Lasso 完整解路径的算法，计算量近似 OLS 的复杂度。

🔑 关键概念

  • 稀疏解 (Sparse Solution) — 解向量中大部分系数为 0 的解。Lasso 因 L1 惩罚项的几何特性天然产生稀疏解，这是它与 Ridge 最本质的区别。
  • λ (Lambda / 正则化强度) — 控制 L1 惩罚力度的超参数。λ 越大，系数压缩越强，解越稀疏。最优 λ 通常通过交叉验证确定。
  • L1 范数 (L1 Norm / Manhattan Norm) — 向量元素绝对值之和，即 ‖w‖₁ = Σ|wⱼ|。Lasso 的惩罚项正是基于 L1 范数。
  • 特征选择 (Feature Selection) — 从所有特征中自动选出对预测最有贡献的子集。Lasso 通过将无用特征系数置零实现"嵌入式"特征选择。
  • 子梯度 (Subgradient) — 对不可导点（如 |w| 在 w=0 处）使用的广义梯度概念。Lasso 优化中软阈值公式正是子梯度条件的产物。
  • 软阈值算子 (Soft-thresholding Operator) — S_λ(z) = sign(z)·max(|z|-λ, 0)。坐标下降法更新每个系数的核心公式，同时实现收缩和选零。
  • 正则化路径 (Regularization Path) — 随 λ 从大到小变化时，各系数取值的轨迹曲线。帮助观察哪些特征先被选入、哪些最后被淘汰。
  • Oracle 性质 (Oracle Property) — 若模型在变量选择上能"认出"正确的稀疏结构（即真正重要的变量被选入，不重要的被排除），且估计效率与已知真实模型相同，则称其具有 Oracle 性质。Adaptive Lasso 满足此性质，普通 Lasso 不完全满足。
  • 收缩 (Shrinkage) — 将回归系数向零方向压缩。Lasso 和 Ridge 都会收缩系数，但 Lasso 的收缩附带置零效果。
  • 偏差-方差权衡 (Bias-Variance Tradeoff) — Lasso 通过引入正则化偏差（将系数向零压缩）来降低模型方差，在适当的 λ 下，总预测误差（偏差²+方差）小于 OLS。
  • p ≫ n 问题 — 当特征数远超样本数时，OLS 没有唯一解。Lasso 在此设定下依然有效，最多可选出 min(n, p) 个非零特征（λ 足够大时至多 n 个）。
  • Warm Start (热启动) — 使用前一个 λ 的解作为当前 λ 优化的初始值。在搜索 λ 路径时，warm start 能大幅加速坐标下降的收敛速度。

🔗 关联

  • 线性回归 (Linear Regression) — Lasso 的基础。当 λ = 0 时 Lasso 退化为普通最小二乘回归。
  • Ridge 回归 (Ridge Regression / L2) — 使用 L2 惩罚的正则化线性回归。Ridge 收缩系数但不置零，Lasso 收缩并置零。二者互为补充。
  • ElasticNet (弹性网络) — L1 + L2 混合正则化。解决了 Lasso 在处理相关特征组时的"随机挑选"问题，是最常用的实际方案。
  • LARS (Least Angle Regression) — 高效求解 Lasso 解的算法。实际上 sklearn 的 Lasso 实现内部使用了 LARS 或坐标下降。
  • 自适应 Lasso (Adaptive Lasso) — 对 Lasso 的改进：不同特征有不同权重的 L1 惩罚，具备 Oracle 性质。
  • 组 Lasso (Group Lasso) — 以"组"为单位进行特征选择，适用于分组特征（如一次性纳入或排除 one-hot 编码的分类变量组）。
  • 主成分回归 (PCR) — 先降维再回归，与 Lasso 在高维数据场景下有相似用途但机制不同。
  • SCAD / MCP — 非凸惩罚函数（Smoothly Clipped Absolute Deviation / Minimax Concave Penalty），能产生更无偏的稀疏解，但优化更复杂。
着重注意
💡 要点 Lasso 能自动做特征选择——将不重要的特征权重精确压缩为零。高维数据（p ≫ n）场景下 Lasso 是最常用的基线方法之一。稀疏解带来的不仅是计算效率，更是模型的可解释性提升。
⚠️ 局限 (1) 相关特征组中随机选一个，组内其他特征被剔除，造成特征选择不稳定；(2) 当 p > n 时最多只能选出 n 个非零特征（n 为样本数）；(3) 对"微相关但都重要"的特征组合不友好；(4) 优化比 Ridge 慢，因为 L1 不可导。
🔧 实践 (1) 标准化所有特征——因为 L1 惩罚对特征尺度敏感；(2) 优先使用 LassoCV 自动调 λ；(3) 用 warm start 加速 λ 搜索路径；(4) 对强相关特征组改用 ElasticNet；(5) λ 路径图是诊断特征重要性的好工具。
🌳 演进 ElasticNet（Zou & Hastie, 2005）结合 L1 + L2 混合正则化，解决了 Lasso 在相关特征组中"随机选一个"的问题——L2 项让组内相关特征能同时被保留或同时被剔除，是实际项目中最推荐的替代方案。
