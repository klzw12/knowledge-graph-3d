多项式回归 Polynomial Regression

在线性回归的基础上引入特征的高次项（$x^2, x^3, \dots$），使模型能够拟合非线性关系。 但其对参数的线性本质不变——参数仍然是线性的，因此仍属于线性模型家族。

📖 定义

多项式回归 (Polynomial Regression) 是线性回归的一种扩展，通过在特征中加入高次项（$x^2, x^3, \ldots, x^n$），使模型能够拟合数据中的非线性关系。

关键洞察：虽然我们给模型提供了"非线性"的特征变换，但模型对参数 $w$ 仍然是线性的。这意味着我们可以使用与线性回归完全相同的优化算法（如梯度下降、最小二乘法）来训练模型。

多项式回归的核心思想是基函数展开 (Basis Function Expansion)——将原始特征 $x$ 通过一组非线性基函数 $\phi(x)$ 映射到高维空间，然后在这个新的特征空间中拟合一个线性模型。

💡 直观理解

面对一个呈弧形分布的数据集（如温度与发电量的关系），直线永远无法拟合出"先升后降"的曲线趋势。但加入 $x^2$ 项后，模型就能产生抛物线的弯曲形状，从而捕捉这种非线性模式。

📐 数学原理

模型形式

一元多项式回归（单特征，$n$ 次多项式）：

$$\hat{y} = b + w_1 x + w_2 x^2 + w_3 x^3 + \cdots + w_n x^n$$

也可写为向量形式的基函数展开：

$$\hat{y} = \mathbf{w}^\mathsf{T} \boldsymbol{\phi}(x) + b$$

其中基函数向量 $\boldsymbol{\phi}(x)$ 定义为：

$$\boldsymbol{\phi}(x) = \begin{bmatrix} x & x^2 & x^3 & \cdots & x^n \end{bmatrix}^\mathsf{T}$$

多特征多项式回归

当有多个特征时，不仅每个特征可以加入高次项，还可以加入特征交互项 (interaction terms)，如 $x_1 x_2$。二元二次多项式：

$$\hat{y} = b + w_1 x_1 + w_2 x_2 + w_3 x_1^2 + w_4 x_2^2 + w_5 x_1 x_2$$

本质：仍是线性模型

这是一个重要的概念区分：多项式回归的参数是线性的，但特征是经过非线性变换的。模型关于参数 $w$ 的偏导数仍然是常数：

$$\frac{\partial \hat{y}}{\partial w_k} = x^k$$

因此，线性回归中的所有优化方法（正规方程、梯度下降）都可以直接应用到多项式回归上。损失函数的凸性也得以保留。

损失函数

使用与线性回归相同的 MSE 损失：

$$\mathcal{L}(\mathbf{w}) = \frac{1}{n}\sum_{i=1}^{n}\bigl(y_i - \hat{y}_i\bigr)^2$$

参数更新规则也完全一致（梯度下降）：

$$w_j := w_j - \alpha \cdot \frac{\partial \mathcal{L}}{\partial w_j}$$
🧮 示例

假设模型为 $\hat{y} = 1 + 0.5x - 0.1x^2 + 0.02x^3$，当 $x=10$：

$\hat{y} = 1 + 0.5(10) - 0.1(100) + 0.02(1000) = 1 + 5 - 10 + 20 = 16$

三次项 $x^3$ 虽然数值巨大，但权重 $w_3=0.02$ 很小，控制了该项的影响力。这正是数值稳定性问题的来源。

📈 模型复杂度与过拟合

多项式的度数（degree）直接决定模型的复杂度。选择合适的度数是多项式回归中最关键的权衡。

度数对拟合的影响

度数拟合效果现象诊断
过低 (degree=1) 欠拟合 (Underfitting) 直线无法捕捉曲线趋势 训练集和验证集的损失都很高
适度 (degree=2~4) 拟合良好 曲线贴合数据真实分布 验证集损失最低
过高 (degree=10+) 过拟合 (Overfitting) 曲线剧烈震荡，精确穿过每个训练点 训练损失极低但验证损失飙升

过拟合的典型表现

当多项式度数过高时，模型会"记住"训练数据中的每一个点，包括噪声。结果是一条在训练点间剧烈波动的曲线，在两端尤其不稳定（Runge 现象）：

  • 训练损伤：接近零，甚至完美拟合所有训练点
  • 验证/测试损伤：非常高，模型在新数据上完全失效
  • 权重膨胀：高次项的权重数值极大，互相抵消以精确拟合训练点
  • 边界发散：在训练数据范围之外，预测值剧烈偏离
⚠️ Runge 现象

当使用高次多项式（如 degree=15）对等距点进行插值时，曲线在区间两端会出现剧烈震荡。例如对函数 $f(x) = 1/(1+25x^2)$ 在 $[-1,1]$ 上的等距采样点做高次多项式拟合，两端误差会发散到无穷大。这是多项式回归过度拟合的经典警示。

偏差-方差权衡

多项式度数选择本质上是偏差-方差权衡 (Bias-Variance Tradeoff) 的体现：

  • 低度数 → 高偏差（模型假设太强），低方差（结果稳定但偏离真实）
  • 适度度数 → 偏差和方差达到最佳平衡
  • 高度数 → 低偏差（可拟合复杂模式），高方差（对数据微小变化极其敏感）

🎯 度数选择

选择最佳多项式度数是一个模型选择 (Model Selection) 问题。没有通用的最优度数——它取决于数据的复杂度和样本量。

验证曲线法

最直接的方法：对不同的度数（degree=1,2,...,D）分别训练模型，然后在验证集上评估性能：

  1. 将数据集划分为训练集和验证集（如 80%/20%）
  2. 对 degree=1 到 degree=10（或更高），训练模型并计算验证集损失
  3. 绘制"度数 vs 验证损失"曲线：找到验证损失最低的度数
  4. 用该度数在完整数据集上重新训练最终模型

交叉验证法

当数据量有限时，使用 K 折交叉验证 能得到更稳定的度数选择：

  • 将数据集分成 K 份（通常 K=5 或 K=10）
  • 每次用 K-1 份训练、1 份验证，重复 K 次
  • 对每个度数，取 K 次验证损失的平均值
  • 选择平均验证损失最低的度数

信息准则法

对于传统统计背景，也可使用 AIC（Akaike Information Criterion）或 BIC（Bayesian Information Criterion）来选择度数，它们在拟合优度和模型复杂度之间施加惩罚：

$$\text{AIC} = 2k - 2\ln(\hat{L})$$
$$\text{BIC} = k\ln(n) - 2\ln(\hat{L})$$

其中 $k$ 是参数数量（即 degree+1），$n$ 是样本数，$\hat{L}$ 是似然函数的最大值。AIC/BIC 值越低越好。

💡 经验法则

在实践中，从 degree=2 开始尝试，逐步增加。大多数真实世界的非线性关系可以用 degree=2~4 的多项式拟合。除非有非常强的理论依据，否则避免使用 degree=10 以上的多项式。

🔧 实践要点

特征缩放至关重要

这是多项式回归中最重要的实践经验。当引入高次项后，不同次方的特征取值差异巨大：

原始值 $x$$x^2$$x^3$$x^4$
0.10.010.0010.0001
1.01.01.01.0
101001,00010,000
10010,0001,000,000100,000,000

不进行特征缩放会导致：

  • 梯度下降收敛极慢——不同维度的梯度量级相差巨大
  • 数值不稳定——过大或过小的数值导致浮点溢出或下溢
  • 正则化失效——L1/L2 惩罚对量级不同的特征不均衡

建议：对每个多项式特征进行 标准化（Z-score） 或缩放到 $[-1, 1]$ 范围。通常在生成多项式特征后进行。

配合正则化

多项式回归的高次项天然容易导致过拟合。与正则化方法配合使用是标准做法：

  • Ridge (L2)：对所有权重施加平方惩罚，平滑地抑制过大的系数。最常用。
  • Lasso (L1)：对权重施加绝对值惩罚，可实现特征选择（将某些高次项系数置零）。
  • ElasticNet：L1+L2 的组合，兼取两者优点。

正则化后的损失函数：

$$\mathcal{L}_{\text{reg}} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 + \lambda\sum_{j=1}^{p}|w_j|^q$$

生成多项式特征的 Python 示例

# 使用 sklearn 生成多项式特征 from sklearn.preprocessing import PolynomialFeatures from sklearn.linear_model import LinearRegression from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler # 创建流水线：多项式特征 → 标准化 → 线性回归 model = Pipeline([ ('poly', PolynomialFeatures(degree=3, include_bias=False)), ('scale', StandardScaler()), ('reg', LinearRegression()) ]) model.fit(X_train, y_train) y_pred = model.predict(X_test)

其他实践建议

  • 从低度数开始：degree=2 试验起，验证集性能不再提升时停止增加
  • 注意外插表现：多项式回归在训练数据范围外的预测极不可靠（高次项会急剧发散）
  • 检查残差图：如果残差呈现明显的系统模式（如 U 形），说明当前度数不足
  • 考虑正交多项式：对高次项使用正交多项式（如 Legendre 多项式）可以减少数值共线性问题
  • 数据量：多项式回归需要比线性回归更多的训练数据——每增加一个度数，模型复杂度增一维

🌳 演进关系

多项式回归在线性回归的基础上增加了非线性拟合能力，但它也有自身的局限——对整体性曲线使用全局多项式，导致边界不稳定。这催生了更灵活的非线性扩展方法。

线性回归
⭐ 多项式回归 加入高次项拟合非线性
岭回归 (Ridge) L2 正则化
Lasso L1 正则化
样条回归 (Spline) 分段多项式, 更灵活
GAM 广义加性模型

🔑 关键概念

  • 多项式度数 (Degree) — 模型中使用的最高的指数。degree=2 为二次（抛物线），degree=3 为三次（S 形曲线）。度数越高，模型越灵活也越危险。
  • 基函数展开 (Basis Function Expansion) — 将原始特征 $x$ 通过一组基函数映射到新的特征空间，然后在这个空间中拟合线性模型。多项式是其中一种基函数选择。
  • 特征交互 (Feature Interaction) — 多特征多项式中的交叉项（如 $x_1 x_2$），让模型能捕捉特征之间的相乘效应。交互项数量随特征数 $p$ 和度数 $d$ 呈 $O(p^d)$ 增长。
  • 过拟合 (Overfitting) — 高次多项式过度适应训练数据（包括噪声）的现象。表现为训练损失极低但泛化能力差，边界发散。
  • 数值稳定性 (Numerical Stability) — 高次项的巨大数值范围导致的浮点计算精度问题。特征缩放是主要的缓解手段。
  • 正交多项式 (Orthogonal Polynomials) — 如 Legendre、Chebyshev 多项式，设计为在特定区间上正交。使用正交多项式可以减少各项之间的多重共线性。
  • Runge 现象 — 高次多项式插值在区间两端剧烈震荡的现象，是高次数过拟合的典型症状。
  • 参数线性 (Parameter Linearity) — 多项式回归的核心属性：模型关于参数 $w$ 是线性的，因此可使用线性回归的全部优化工具。

🔗 关联

  • 线性回归 — 多项式回归的基础。当 degree=1 时退化为普通线性回归。理解线性回归的损失函数、梯度下降、超参数调优等是掌握多项式回归的前提。
  • Ridge / Lasso 回归 — 正则化方法与多项式回归是天作之合。高次项天然容易过拟合，正则化提供了有效的抑制手段。在实践中几乎总是联合使用。
  • 样条回归 (Spline Regression) — 多项式回归的"局部化"升级版。用分段低次多项式（样条）替代全局高次多项式，在每个小段内拟合低次曲线并在连接点光滑衔接。解决全局多项式边界不稳定的问题。
  • 广义加性模型 (GAM) — 更大的框架：每个特征通过一个非线性光滑函数 $f_j(x_j)$ 建模，这些函数可以是样条，也可以是多项式。加性结构意味着 $E[Y] = f_1(x_1) + f_2(x_2) + \cdots + f_p(x_p)$，比全交互的多项式回归更高效。
  • 核方法与 SVM — 从不同的角度解决"非线性特征映射"问题。核技巧通过核函数隐式地在高维空间中计算内积，避免了显式地生成高次特征。
着重注意
💡 要点 多项式回归仍然属于线性模型——参数 $w$ 是线性的。这意味你可以用线性回归的全部优化工具（正规方程、梯度下降），损失函数仍是凸的，保证能找到全局最优解。
⚠️ 局限 高次项导致数值范围爆炸（如 $x=100$ 时 $x^{10}=1\times10^{20}$）；外插能力差，在训练数据范围外的预测不可靠；全局多项式曲线在两端（Runge 现象）剧烈震荡；需要比线性回归更多的数据。
🔧 实践 必须做特征缩放（标准步）；始终配合正则化（Ridge/Lasso）控制过拟合；从 degree=2 开始尝试，用验证曲线确定最佳度数；检查残差图诊断是否需要更高次；处理交互特征时注意特征数量爆发式增长。
🌳 演进 多项式回归是通向更灵活方法的中间站——样条回归（分段低次多项式）解决全局多项式不稳定的问题；广义加性模型 (GAM) 对每个特征使用独立的光滑函数，是更灵活、可解释性更强的非线性扩展。
