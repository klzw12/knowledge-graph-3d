集成学习 Ensemble Learning

通过组合多个弱学习器来构建更强大、更稳定的模型

目录

📖 定义

Ensemble Learning — 训练多个基学习器并组合它们的预测结果，以获得比单个模型更好的泛化性能。"三个臭皮匠，顶个诸葛亮"。

📐 数学原理

Bagging（并行）

对训练集进行 Bootstrap 采样，训练多个模型后投票/平均。

$$ \text{Bagging: } \hat{f}(x) = \frac{1}{M}\sum_{m=1}^M f_m(x) $$

Boosting（串行）

依次训练模型，每个新模型重点关注前一个模型的错误样本。

$$ \text{Boosting: } \hat{f}(x) = \sum_{m=1}^M \alpha_m f_m(x) $$

🔑 关键方法

  • Bagging 类 — 随机森林
  • Boosting 类 — AdaBoost、XGBoost、LightGBM、CatBoost
  • Stacking — 元学习器组合

🔗 关联

  • 决策树（基学习器）
  • XGBoost（进阶）
着重注意
💡 要点 基学习器需要"好而不同"——准确性 + 多样性才能有效集成
⚠️ 局限 模型可解释性差，计算和存储成本高
🔧 实践 随机森林是开箱即用的好基线，XGBoost 是表格数据的竞赛之王
