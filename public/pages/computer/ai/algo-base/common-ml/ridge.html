📖 定义

343|

岭回归 (Ridge Regression) 是一种专用于多重共线性 (multicollinearity) 数据分析的有偏估计回归方法。它在普通最小二乘法 (OLS) 的损失函数中引入 L2 正则化惩罚项，迫使模型权重向零收缩但不为零。

344|

核心思想：在保留所有特征的前提下，通过惩罚大的权重值来控制模型复杂度。当特征之间存在高度相关性时，普通线性回归的系数估计会变得不稳定（方差大），而 Ridge 通过加入 λI 项使矩阵可逆，保证解的唯一性和稳定性。

345| 346|

为什么需要岭回归？

347|

当特征维度 p 接近样本量 n 时，$(X^\mathsf{T}X)$ 矩阵接近奇异 (singular)，导致 OLS 解严重不稳定。Ridge 在 $X^\mathsf{T}X$ 的对角线上加入 λ，确保矩阵总是可逆的。

348| 349|
350| 351| 352| 353| 354| 355| 356|
情况OLS 表现Ridge 表现
良态数据 (n ≫ p)稳定、无偏接近 OLS（λ 小）
多重共线性方差极大、系数不稳定系数稳定、估计可靠

💡 直觉理解
361|

想象你试图用多个高度相关的特征（如"房屋面积"和"房屋房间数量"）预测房价。OLS 可能给面积分配一个很大的正系数，同时给房间数量分配一个很大的负系数——两者相互抵消，单看每个系数都不合理。Ridge 通过惩罚大系数，迫使这两个相关特征的系数更均衡、更合理。

📐 数学原理

368| 369|

损失函数

370|

岭回归在 OLS 的 MSE 损失基础上增加 L2 惩罚项：

371|
$$L(\mathbf{w}) = \underbrace{\frac{1}{n}\sum_{i=1}^{n}(y_i - \mathbf{w}^\mathsf{T}\mathbf{x}_i)^2}_{\text{MSE 损失}} + \lambda\underbrace{\sum_{j=1}^{p} w_j^2}_{\text{L2 惩罚}}$$
372|

其中：

373|
    374|
  • λ (lambda) — 正则化强度超参数，λ ≥ 0。λ = 0 退化为 OLS
    • 375|
  • $w_j$ — 第 j 个特征的权重（注意：偏置 b 通常不参与正则化）
    • 376|
  • $\sum w_j^2$ — 权重的 L2 范数平方，即 $\|\mathbf{w}\|_2^2$
    • 377|
378| 379|

矩阵形式

380|
$$L(\mathbf{w}) = \|\mathbf{y} - X\mathbf{w}\|_2^2 + \lambda\|\mathbf{w}\|_2^2$$
381| 382|

解析解（闭式解）

383|

对损失函数求导并令梯度为零，得到岭回归的解析解：

384|
$$\mathbf{w}_{\text{ridge}} = (X^\mathsf{T}X + \lambda I)^{-1}X^\mathsf{T}\mathbf{y}$$
385|

关键观察：

386|
    387|
  • 加入 λI 保证可逆 — 即使 $X^\mathsf{T}X$ 是奇异的，$X^\mathsf{T}X + \lambda I$ 也一定是满秩可逆矩阵
    • 388|
  • λ → 0 — 解析解退化为 OLS 的 $\mathbf{w}_{\text{OLS}} = (X^\mathsf{T}X)^{-1}X^\mathsf{T}\mathbf{y}$
    • 389|
  • λ → ∞ — 权重趋近于 0，模型趋近于常数均值预测
    • 390|
  • 偏置 — 实际中偏置项 b 单独处理（不进入惩罚项），一般等价于先对 y 和 X 进行中心化
    • 391|
392| 393|

SVD 视角

394|

设 $X = UDV^\mathsf{T}$ 为 X 的奇异值分解，则：

395|
$$\mathbf{w}_{\text{ridge}} = \sum_{j=1}^{p} \frac{d_j}{d_j^2 + \lambda} (u_j^\mathsf{T}\mathbf{y}) v_j$$
396|

对比 OLS 的 $\mathbf{w}_{\text{OLS}} = \sum_{j=1}^{p} \frac{1}{d_j} (u_j^\mathsf{T}\mathbf{y}) v_j$：

397|

Ridge 在分母中加入了 λ，对小奇异值方向（方差大的方向）的权重进行更强地收缩。因子 $\frac{d_j^2}{d_j^2 + \lambda}$ 称为收缩因子 (shrinkage factor)，奇异值越小收缩越强。

📉 L2 正则化效应

403| 404|

权重衰减 (Weight Decay)

405|

L2 正则化的一个直观效果是权重衰减：在梯度下降更新中，每次迭代时权重都会先乘以一个小于 1 的因子：

406|
$$w_j^{(t+1)} = w_j^{(t)} - \eta\Bigl(\frac{\partial \text{MSE}}{\partial w_j} + 2\lambda w_j^{(t)}\Bigr) = (1 - 2\eta\lambda)w_j^{(t)} - \eta\frac{\partial \text{MSE}}{\partial w_j}$$
407|

其中 $(1 - 2\eta\lambda)$ 就是衰减因子。每次迭代权重被迫向零靠拢，λ 越大衰减越强。

408| 409|

λ 对权重的影响

410|

随着 λ 从 0 逐渐增大：

411|
    412|
  • 权重绝对值整体下降 — 所有特征系数向零收缩
    • 413|
  • 高方差方向优先收缩 — 对应较小奇异值的方向（通常是不稳定特征组合）被惩罚更多
    • 414|
  • 所有权重被保留 — Ridge 不会将任何权重精确置零（区别于 Lasso）
    • 415|
  • 相关特征系数趋于平衡 — 高度相关的一组特征各自的权重变得更均匀
    • 416|
417| 418|

特征值缩放的作用

419|

L2 惩罚项 $\sum w_j^2$ 对特征的尺度敏感。如果某个特征的数值范围很大（如"收入"以万元为单位），其对应的权重自然很小；反之，数值范围很小的特征（如"年龄"）对应较大的权重。这导致：

420|
    421|
  • 标准化的必要性 — 使用 Ridge 前必须对特征进行标准化（均值 0、方差 1），否则惩罚项对不同特征不公平
    • 422|
  • 等权收缩 — 标准化后所有特征的尺度一致，正则化惩罚均匀作用于每个特征
    • 423|
424| 425|
426| 427| 428| 429| 430| 431| 432| 433|
λ 值正则化强度权重规模模型复杂度
λ = 0无正则化OLS 无偏估计最高（可能过拟合）
λ = 0.01轻微轻微收缩略有降低
λ = 1中等明显收缩显著降低
λ = 10强大幅收缩低
λ → ∞极致趋近零欠拟合（近似常数模型）

🧮 数值示例
438|

假设 OLS 解为 $w_{\text{OLS}} = [10, -8, 0.5]^\mathsf{T}$，加入 λ = 1 后：

439|

$w_{\text{ridge}} = (X^\mathsf{T}X + I)^{-1}X^\mathsf{T}\mathbf{y}$，结果大致为 $[5, -4, 0.3]^\mathsf{T}$ 左右——大的正负系数被显著缩小，小的系数也略有收缩。特征选择和符号通常被保留。

📊 偏差-方差权衡

446| 447|

偏差 (Bias) 与方差 (Variance)

448|

模型的总泛化误差可以分解为三个部分：

449|
$$\mathbb{E}\bigl[(y - \hat{y})^2\bigr] = \underbrace{\text{Bias}(\hat{y})^2}_{\text{偏差}^2} + \underbrace{\text{Var}(\hat{y})}_{\text{方差}} + \underbrace{\sigma^2}_{\text{噪声}}$$
450|

岭回归的核心机制就在于调节偏差-方差权衡 (Bias-Variance Tradeoff)：

451|
    452|
  • OLS（λ = 0） — 无偏估计（偏差=0），但方差大，尤其在多重共线性时
    • 453|
  • Ridge（λ > 0） — 引入偏置（系数被有意缩小），但方差大幅降低
    • 454|
455| 456|

量化分析

457|

岭回归估计的偏差和方差可由下式量化：

458|
$$\text{Bias}(\mathbf{w}_{\text{ridge}}) = \mathbb{E}[\mathbf{w}_{\text{ridge}}] - \mathbf{w}_{\text{true}} = -\lambda (X^\mathsf{T}X + \lambda I)^{-1}\mathbf{w}_{\text{true}}$$
459|
$$\text{Var}(\mathbf{w}_{\text{ridge}}) = \sigma^2 (X^\mathsf{T}X + \lambda I)^{-1} X^\mathsf{T}X (X^\mathsf{T}X + \lambda I)^{-1}$$
460|

关键结论：

461|
    462|
  • 偏差随 λ 增大而 增大（有偏估计）
    • 463|
  • 方差随 λ 增大而 减小（估计更稳定）
    • 464|
  • 存在一个最优 λ 使总预测误差最小——即在偏差和方差之间找到最佳平衡点
    • 465|
466| 467|

泛化能力

468|

虽然在训练数据上 Ridge 的误差比 OLS 略高（因为加入了偏置），但在测试数据上 Ridge 通常表现得更好：

469|
    470|
  • OLS 对训练数据过度适应，在新数据上表现差
    • 471|
  • Ridge 通过收缩权重，抑制了对训练噪声的拟合，从而提升了泛化能力
    • 472|

⚙️ 正则化参数 λ 的选择

487| 488|

交叉验证选择 λ

489|

λ 是 Ridge 最重要的超参数，通常通过交叉验证 (Cross-Validation) 选择：

490|
    491|
  1. 在对数尺度上定义候选 λ 值网格（如 0.01, 0.05, 0.1, 0.5, 1, 5, 10, 50, 100）
    2. 492|
  2. 对每个 λ 进行 k 折交叉验证（常用 k=5 或 k=10）
    3. 493|
  3. 选择使交叉验证均方误差 (CV-MSE) 最小的 λ
    4. 494|
  4. 也可使用"1-SE 规则"（one-standard-error rule）选择更简约的模型
    5. 495|
496|
$$\lambda^* = \arg\min_{\lambda} \frac{1}{k}\sum_{i=1}^{k} \text{MSE}_i(\lambda)$$
