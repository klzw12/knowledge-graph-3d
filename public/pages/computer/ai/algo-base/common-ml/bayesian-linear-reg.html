📖 定义

341|

贝叶斯线性回归 (Bayesian Linear Regression) 是线性回归的贝叶斯推广。与经典线性回归将权重 $\mathbf{w}$ 视为未知但固定的常数不同，贝叶斯线性回归将权重视为随机变量，并为其指定一个先验分布 (prior distribution)，然后利用观测数据更新为后验分布 (posterior distribution)。

342|

这一概率化视角带来了两个关键优势：

343|
    344|
  • 不确定性量化 — 模型不仅输出点预测 $\hat{y}$，还能给出预测的置信区间（预测分布），反映模型对预测结果的信心程度
    • 345|
  • 先验知识融合 — 在数据稀疏或噪声较大的场景下，先验知识可以引导模型朝合理方向学习，防止过拟合
    • 346|
347| 348|
349|
💡 直觉理解
350|

想象你在教一个学生画一条线穿过数据点。经典线性回归告诉学生"在数据中找一条最佳直线，画出来就好"。贝叶斯线性回归则让学生先画一条"大概的线"（先验），然后看到数据后更新自己的判断——"我现在更确定一些了，但某些区域我还是不太确定"（后验）。最终给出的不是一条线，而是一个可能的线条分布。

与频率派的核心差异

354|
355| 356| 357| 358| 359| 360| 361| 362| 363|
对比维度频率派 (Frequentist)贝叶斯 (Bayesian)
参数 $\mathbf{w}$未知但固定的常数随机变量，服从概率分布
估计方式点估计（如 MLE, OLS）后验分布 $p(\mathbf{w} \mid X, \mathbf{y})$
预测输出一个点（最优估计值）一个预测分布（均值 + 方差）
不确定性来源仅采样不确定性参数不确定性 + 噪声不确定性
处理小样本方差大，容易过拟合先验提供正则化，鲁棒性强
计算复杂度低（闭式解 / GD）较高（后验积分）
364|
365| 366|

本质上，贝叶斯线性回归将统计推断提升为概率推断——从一个确定性的最优解问题，转变为从数据中学习参数分布的问题。

📐 数学原理

372| 373|

1. 模型设定

374|

与经典线性回归相同，假设输出 $y$ 与输入 $\mathbf{x}$ 之间存在线性关系，并附加高斯噪声：

375|
$$y = \mathbf{w}^\mathsf{T}\mathbf{x} + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, \sigma^2)$$
376|

即似然函数 (likelihood) 为：

377|
$$p(y \mid \mathbf{x}, \mathbf{w}, \sigma^2) = \mathcal{N}(y \mid \mathbf{w}^\mathsf{T}\mathbf{x}, \sigma^2)$$
378|

对所有 $n$ 个独立观测样本，似然为：

379|
$$p(\mathbf{y} \mid X, \mathbf{w}, \sigma^2) = \prod_{i=1}^{n} \mathcal{N}(y_i \mid \mathbf{w}^\mathsf{T}\mathbf{x}_i, \sigma^2) = \mathcal{N}(\mathbf{y} \mid X\mathbf{w}, \sigma^2 I)$$
380| 381|

2. 先验分布 (Prior)

382|

对权重 $\mathbf{w}$ 引入高斯先验，假设各权重独立同分布：

383|
$$p(\mathbf{w}) = \mathcal{N}(\mathbf{w} \mid \mathbf{0}, \tau^2 I) = \prod_{j=1}^{p} \frac{1}{\sqrt{2\pi\tau^2}} \exp\!\left(-\frac{w_j^2}{2\tau^2}\right)$$
384|

其中 $\tau^2$ 是先验方差，控制我们对权重幅度的先验信念：

385|
    386|
  • $\tau^2$ 大 — 先验较弱（对权重大小没有强烈约束），后验主要由数据驱动
    • 387|
  • $\tau^2$ 小 — 先验较强（强烈认为权重接近 0），后验偏向收缩
    • 388|
389|

也可对噪声方差 $\sigma^2$ 引入逆伽马先验（此时构成共轭先验），但为简明起见，通常先固定 $\sigma^2$ 或通过经验贝叶斯估计。

390| 391|

3. 后验推断 (Posterior Inference)

392|

根据贝叶斯定理：

393|
$$p(\mathbf{w} \mid X, \mathbf{y}) = \frac{p(\mathbf{y} \mid X, \mathbf{w})\,p(\mathbf{w})}{p(\mathbf{y} \mid X)} \propto p(\mathbf{y} \mid X, \mathbf{w})\,p(\mathbf{w})$$
394|

由于高斯先验和高斯似然是共轭的，后验分布也是高斯分布，有闭式解：

395|
$$p(\mathbf{w} \mid X, \mathbf{y}) = \mathcal{N}(\mathbf{w} \mid \boldsymbol{\mu}_n, \Sigma_n)$$
396|

其中：

397|
$$\Sigma_n = \left(\frac{1}{\sigma^2} X^\mathsf{T} X + \frac{1}{\tau^2} I\right)^{-1}$$
398|
$$\boldsymbol{\mu}_n = \frac{1}{\sigma^2} \Sigma_n X^\mathsf{T} \mathbf{y}$$
399|

关键观察：

400|
    401|
  • 后验均值 $\boldsymbol{\mu}_n$ — 等价于 Ridge 回归的 MAP 估计（$\lambda = \sigma^2 / \tau^2$）
    • 402|
  • 后验协方差 $\Sigma_n$ — 量化了权重估计的不确定性——协方差矩阵越大，我们对权重越不确定
    • 403|
  • 数据越多 — $\Sigma_n$ 的特征值越小，后验越集中（不确定性降低）
    • 404|
  • 先验方差 $\tau^2$ — 控制正则化强度：$\tau^2$ 越小（先验越强），后验均值越收缩向零
    • 405|
406| 407|

4. 预测分布 (Predictive Distribution)

408|

对于新输入 $\mathbf{x}_*$，预测分布通过对权重后验积分得到：

409|
$$p(y_* \mid \mathbf{x}_*, X, \mathbf{y}) = \int p(y_* \mid \mathbf{x}_*, \mathbf{w})\,p(\mathbf{w} \mid X, \mathbf{y})\,d\mathbf{w}$$
410|

这一积分同样有闭式解（高斯-高斯共轭性）：

411|
$$p(y_* \mid \mathbf{x}_*, X, \mathbf{y}) = \mathcal{N}(y_* \mid \boldsymbol{\mu}_n^\mathsf{T}\mathbf{x}_*, \;\sigma_n^2(\mathbf{x}_*))$$
412|

其中预测方差为：

413|
$$\sigma_n^2(\mathbf{x}_*) = \sigma^2 + \mathbf{x}_*^\mathsf{T} \Sigma_n \mathbf{x}_*$$
414|

预测方差包含两个部分：

415|
    416|
  • $\sigma^2$ — 固有噪声（aleatoric uncertainty）：数据本身不可消除的随机噪声
    • 417|
  • $\mathbf{x}_*^\mathsf{T} \Sigma_n \mathbf{x}_*$ — 认知不确定性（epistemic uncertainty）：由于对权重 $\mathbf{w}$ 的不确定性而导致的不确定性；数据越多/越靠近训练数据，这项越小
    • 418|
419| 420|
421|
💡 预测方差的含义
422|

在训练数据稀疏的区域，$\mathbf{x}_*$ 远离训练数据中心，$\mathbf{x}_*^\mathsf{T} \Sigma_n \mathbf{x}_*$ 会变大——模型在它不熟悉的地方做出预测时，会如实反映出更高的不确定性。这是贝叶斯线性回归区别于普通线性回归的核心特征。

🔬 与普通线性回归的关系

429| 430|

MAP 估计等价于 Ridge 回归

431|

如果只关心后验的众数 (mode)，即最大后验估计（MAP），那么对后验取对数并最大化：

432|
$$\mathbf{w}_{\text{MAP}} = \arg\max_{\mathbf{w}} \log p(\mathbf{w} \mid X, \mathbf{y}) = \arg\max_{\mathbf{w}} \bigl[\log p(\mathbf{y} \mid X, \mathbf{w}) + \log p(\mathbf{w})\bigr]$$
433|

代入高斯似然和高斯先验后：

434|
$$\mathbf{w}_{\text{MAP}} = \arg\min_{\mathbf{w}} \left[ \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - \mathbf{w}^\mathsf{T}\mathbf{x}_i)^2 + \frac{1}{2\tau^2}\sum_{j=1}^{p} w_j^2 \right]$$
435|

两边乘以 $2\sigma^2$ 后：

436|
$$\mathbf{w}_{\text{MAP}} = \arg\min_{\mathbf{w}} \left[ \sum_{i=1}^{n}(y_i - \mathbf{w}^\mathsf{T}\mathbf{x}_i)^2 + \frac{\sigma^2}{\tau^2}\sum_{j=1}^{p} w_j^2 \right]$$
437|

令 $\lambda = \sigma^2 / \tau^2$，这正是 Ridge 回归 的目标函数：

438|
$$\mathbf{w}_{\text{MAP}} = \arg\min_{\mathbf{w}} \left[ \text{MSE} + \lambda \|\mathbf{w}\|_2^2 \right] = \mathbf{w}_{\text{ridge}}$$
439| 440|
441| 442| 443| 444| 445| 446|
方法估计方式输出不确定性
OLS（最小二乘）MLE（无先验）点估计 $\hat{y}$❌ 无
Ridge 回归MAP（高斯先验）点估计 $\hat{y}$❌ 无（仅隐式）
贝叶斯线性回归全后验推断预测分布 $p(y_*)$✅ 完整

频率派 vs 贝叶斯哲学对比

450|

两者看待统计推断的方式有着根本差异：

451|
    452|
  • 频率派认为参数是固定但未知的常数，通过最大化似然（MLE）或最小化损失得到"最佳"点估计。置信区间解释为：如果重复采样无限次，区间覆盖真实参数的频率为 95%
    • 453|
  • 贝叶斯派认为参数是随机变量，通过先验 + 数据更新为后验分布。可信区间解释为：给定观测数据，参数落在该区间内的概率为 95%——这是更直接的、更符合直觉的不确定性陈述
    • 454|
455| 456|

🧮 数值示例
458|

假设单变量线性回归 $y = wx + b + \varepsilon$，仅有 5 个数据点。OLS 给出 $w=2.3$，贝叶斯线性回归的后验为 $p(w) = \mathcal{N}(2.3, 0.9^2)$。这告诉我们："最可能的斜率是 2.3，但真实斜率有 68% 的概率落在 [1.4, 3.2] 区间内。" 而在数据稀疏的区域（如 $x=10$），预测区间可能会宽到 $[15, 35]$——模型诚实地反映了其不确定性。

📊 预测区间 (Prediction Interval)

465| 466|

点估计 vs 分布估计

467|

普通线性回归只能输出一个预测值 $\hat{y}_*$，如果要计算置信区间，需要额外进行频率派推断——这通常假设模型参数已知（用点估计代替），忽略了参数估计自身的不确定性。

468|

贝叶斯线性回归则天然输出预测分布 $p(y_* \mid \mathbf{x}_*, X, \mathbf{y})$，其均值和方差同时给出。这意味着：

469|
    470|
  • 预测均值 — 最优点预测（与 Ridge MAP 一致）
    • 471|
  • 预测方差 — 自动包含参数不确定性 + 固有噪声
    • 472|
473| 474|

数据稀疏区域的不确定性

475|

预测方差 $\sigma_n^2(\mathbf{x}_*) = \sigma^2 + \mathbf{x}_*^\mathsf{T} \Sigma_n \mathbf{x}_*$ 随 $\mathbf{x}_*$ 的位置而变化：

476|
477| 478| 479| 480| 481| 482| 483|
$\mathbf{x}_*$ 位置预测方差不确定性原因
靠近训练数据中心小（≈ $\sigma^2$）低对权重有充分信息
远离训练数据中心大高外推区域，参数不确定性放大
训练数据密集极小最低$\Sigma_n$ 很小，认知不确定性近乎为零
训练数据稀疏极大最高$\Sigma_n$ 很大，模型正外推到未知区域
484|
485| 486|

95% 预测区间

487|

给定预测分布 $p(y_* \mid \mathbf{x}_*) = \mathcal{N}(\mu_*, \sigma_*^2)$，95% 预测区间为：

488|
$$\text{PI}_{95\%} = [\mu_* - 1.96\,\sigma_*,\; \mu_* + 1.96\,\sigma_*]$$
489|

这个区间比普通线性回归的置信区间更宽（因为包含了参数不确定性），因此也更诚实——反映的是"模型实际知道多少"，而非"假设参数已知下的最优情况"。

490| 491|
492|
🔬 重要特性
493|

设想一个气温预测任务：训练数据集中在 10°C~20°C，现在要预测 40°C 时的某个指标。普通线性回归给出 $\hat{y}=50\pm5$（恒定宽度的置信区间），而贝叶斯线性回归给出 $\hat{y}=50\pm18$——因为远离训练数据，模型"自知"不确定性很大。这在高风险决策（如医学、工程）中至关重要，区分了"模型自信的预测"和"模型在瞎猜"。
