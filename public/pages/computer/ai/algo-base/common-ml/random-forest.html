随机森林 Random Forest

基于 Bagging 的决策树集成方法，引入随机特征选择来降低树之间的相关性

📄 Random Forests, Leo Breiman 2001

📖 定义

Random Forest — 在 Bagging 基础上，每棵树在分裂时只随机选取部分特征进行考查，进一步降低了决策树之间的相关性。是目前最"开箱即用"的机器学习算法之一。

📐 数学原理

Bagging

对原始数据集进行 B 次 Bootstrap 采样（有放回），每次得到一个子集训练一棵决策树。

随机特征子空间

每棵树分裂时，从全部 M 个特征中随机选取 m 个候选特征（分类通常 m=√M，回归 m=M/3）。

输出

分类取众数：

$$\hat{y} = \text{mode}\{\hat{y}_b\}_{b=1}^B$$

回归取平均：

$$\hat{y} = \frac{1}{B}\sum_{b=1}^B \hat{y}_b$$

泛化误差上界

$$\text{泛化误差} \leq \frac{\bar{\rho}(1 - s^2)}{s^2}$$

其中 ρ̄ 是树间相关性，s 是单棵树强度。

🔑 关键概念

  • Bootstrap 采样 — 有放回抽样
  • OOB (Out-of-Bag) — 袋外样本用于无偏评估
  • 特征重要性 — 基于不纯度减少量
  • 随机性 — 降低方差的关键

🔗 关联

  • 决策树（基学习器）
  • XGBoost（Boosting 对比）
  • ExtraTrees（更随机的变体）
着重注意
💡 要点 随机森林几乎不需要调参就能获得不错的结果，OOB 误差可替代交叉验证
⚠️ 局限 模型体积大、预测慢，对极端值回归能力弱
🔧 实践 n_estimators=100 起步，用 OOB 评估；特征重要性分析可以帮助筛选特征
